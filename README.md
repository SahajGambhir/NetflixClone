# 🎬 Netflix India – Landing Page Clone

A responsive Netflix India landing page clone built using **HTML, CSS, and JavaScript**. This project recreates the look and feel of Netflix's homepage, featuring a hero section, trending movies carousel, membership benefits, FAQs, and footer.

This project was created as a front-end development practice project to improve my understanding of website structure, styling, layouts, and basic JavaScript interactions.

## 🚀 Features

- 🎨 **Netflix-Inspired UI** – Dark theme and Netflix-style visual design.
- 🧭 **Navigation Bar** – Netflix logo, language button, and sign-in button.
- 🎥 **Hero Section** – Main banner with membership information and email input.
- 🔥 **Trending Movies** – Horizontally scrollable movie cards with navigation arrows.
- ✨ **Reasons to Join** – Sections highlighting Netflix's features and benefits.
- ❓ **FAQ Section** – Frequently asked questions displayed in a clean layout.
- 📧 **Email Input Sections** – Email fields with Get Started buttons.
- 🔗 **Footer Navigation** – Links to FAQs, account information, privacy, and more.

## 🛠️ Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layout, colors, and responsive design.
- **JavaScript** – Interactive horizontal scrolling for the trending movies section.
- **SVG** – Vector icons and decorative graphics.
